# algoritmos-java

Algorithms course project (Universidad Central del Ecuador, SIS4-002).
Work in progress: this README is completed in a later phase.

## Requirements
- Java 21 or newer (the project compiles with `maven.compiler.release = 21`)
- Maven 3.9+
- Git

## Build, test and run
```bash
mvn clean compile                                  # compile
mvn test                                           # run JUnit 5 tests
java -cp target/classes ec.edu.uce.algoritmos.Main # run the console app
```
